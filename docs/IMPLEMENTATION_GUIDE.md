# 小学コレ！理科 — クイズ説明文拡張プロジェクト

**実施期間**: 2026年9月2日
**対象**: 全47ステージ × 10問 = 470問のクイズ説明文
**目標**: 子ども向けの充実した学習説明への変更

---

## 🎯 プロジェクト目標

### 現状
- **説明文の長さ**: 150-200文字（短い）
- **言語レベル**: やや技術的
- **構造**: 平坦（段落がない）
- **実例**: ほぼなし
- **ビジュアルタグ**: なし

### 目標状態
- **説明文の長さ**: 400-600文字（2.5〜3倍に拡大）
- **言語レベル**: 小学生向けの親切な日本語
- **構造**: 見出し付き、段階的説明
- **実例**: 3〜4個の具体的な実生活例
- **ビジュアルタグ**: `imageKeyword` フィールド追加

---

## 📝 改善前後の比較

### 例1: 昆虫の体の部分（Stage 3-001, Q1）

#### ❌ BEFORE (150文字)
```
昆虫の体は頭・胸・腹の3つの部分に分かれています。
この3つの部分が昆虫の大事な特徴です。
```

#### ✅ AFTER (560文字)
```
昆虫のからだは、3つの大事な部分に分かれています。

【その① 頭（あたま）】
目・口・触角（しょっかく）がついているところ。昆虫はここで周りを見たり、
食べ物を探したり、仲間と話したりします。

【その② 胸（むね）】
6本の脚と翅（はね）がついているところ。ここが昆虫のパワーの源です。
バッタがぴょんぴょん跳ぶのも、蝶が空を飛ぶのも、すべてこの胸の力です。

【その③ 腹（はら）】
栄養を蓄える場所で、子孫を産む大切なところ。昆虫が食べた栄養はここに蓄えられます。

【実生活の例】
・バッタを観察してみてください。もし体を3つに分けて数えることができたら、それは昆虫です
・もし体が2つだけなら、それはクモかもしれません（クモの仲間は体が2つだけです）

【つまりこういうこと】
昆虫は「頭・胸・腹」の3つセットで一つの昆虫になっています。
この3つが揃っていることが、昆虫を昆虫にしている秘密なんです。
```

**改善ポイント**:
- 3.7倍の文字数に拡大
- 見出しで視覚的に整理
- 3段階の詳細説明で概念を解体
- 2つの実生活例で理解を助ける
- 最後の「つまり」で統合

## 💡 コンテンツ品質向上のポイント

### ✅ DO（やること）

1. **子どもが見たことある例を選ぶ**
   - 「バッタを観察」「冷蔵庫」「キャンプ」など日常的な例

2. **「なぜ？」に答える**
   - 「〜だから」「〜のため」で因果関係を明確に

3. **粒子・力・エネルギーの視点から説明**
   - 小学生にも分かる「見えない世界」の説明

4. **段階的に深掘り**
   - 第1段階：基本概念
   - 第2段階：具体的な仕組み
   - 第3段階：実生活への応用

### ❌ DON'T（やらないこと）

1. ❌ 専門用語をそのままにする（ふりがな必須）
2. ❌ 子どもに馴染みがない例
3. ❌ 文字数だけ増やす（内容なし）
4. ❌ 複雑すぎる文構造
5. ❌ 説明が相互に矛盾する

## 🎓 学年別の言語難度調整例

### 小学3年生向け（Stage 3)
```
短い文 / 簡単な漢字 / 日常語中心

```

### 小学4年生向け（Stage 4）

```
専門用語（ふりがな付き） / 複雑な概念

```

```
例: 「CₓHᵧ + O₂ → CO₂ + H₂O という化学反応」
```
