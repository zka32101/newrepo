| 項目 | Before | After |
|-----|--------|-------|
| **文字数** | 150-200文字 | 400-600文字（2.5-3倍） |
| **構造** | 平坦 | 見出し+段落（3-5段落） |

## 📋 テンプレートを選ぶ

### 🔹 パターン①「複数の部分・要素」がある
（昆虫の部位、磁石の極、植物の器官など）

```dart
'correctReason': '''【導入文】は、【N個】の【要素名】に分かれています。

【その① 要素1】
説明。働き。

【その② 要素2】
説明。働き。

【実生活の例】
・例1
・例2

【つまり】
統合メッセージ。なぜ大事か。
''',
'imageKeyword': 'concept_aspect_detail',
```

**使用例**:
- 昆虫の体（頭・胸・腹）→ insect_body_parts_diagram
- 磁石の極（N・S） → magnet_poles_attraction_repulsion
- 植物の器官（根・茎・葉） → plant_organs_functions

---

### 🔹 パターン②「条件・段階」がある
（発芽の3条件、燃焼の三要素、温度変化の3段階など）

```dart
'correctReason': '''【現象】には「【N個】の条件」があります。

【条件①】
説明。例。

【条件②】
説明。例。

【実生活の例】
・具体例1
・具体例2
・具体例3

【つまり】
統合メッセージ。
''',
'imageKeyword': 'process_condition_requirement',
```

**使用例**:
- 発芽の3条件（水・温度・空気） → seed_germination_three_conditions
- 燃焼の三要素（燃料・酸素・熱） → combustion_triangle_fuel_oxygen_heat
- 力の3要素 → force_three_components

---

### 🔹 パターン③「原理・仕組み」がある
（熱膨張の仕組み、磁化の原理、光屈性など）

```dart
'correctReason': '''【現象】は、実は【本当の仕組み】です。

【【見た目 / なぜそうなる】】
詳細。粒子・力・エネルギーレベルの説明。

【実生活の例】
・例1
・例2
・例3

【つまり】
本質を1文で。
''',
'imageKeyword': 'principle_mechanism_process',
```

**使用例**:
- 熱膨張の仕組み → thermal_expansion_metal_bridge
- 水の異常膨張 → water_anomalous_expansion_ice_float
- 根の重力屈性 → root_geotropism_gravity_growth

## 🎯 各セクションの書き方

### ✅ 導入文のコツ

```
❌ 「〜です」（素っ気ない）
→ 「〜には、〜があります」（ハッキリしている）

❌ 「〜に分かれています」
→ 「昆虫のからだは、3つの大事な部分に分かれています」（具体的）
```

### ✅ 見出しの構造

```
【その① 〇〇】      ← 小学3-4年向け（番号で視覚化）
【条件① 〇〇】      ← パターンを明確に
【段階① 〇〇】      ← 時系列・段階を示す
```

### ✅ 説明文のポイント

| やること | 例 |
|---------|-----|
| 働きを説明 | 「この〇〇は△△の役目をします」 |
| 例を挙げる | 「バッタがぴょんぴょん跳ぶのは、この〇〇の力です」 |
| 比較する | 「〇〇は△△と違って、〜」 |
| 「なぜ？」を答える | 「〜だから、〜になります」 |

### ✅ 実生活例のチェック

```
❌ 「科学者は...」「実験室では...」
→ ✅ 「冷蔵庫に〜」「庭で〜」「お風呂で〜」

❌ 「複雑な理論」
→ ✅ 「見たことある / 触ったことある」

最低3個、最大4個が目安
```

### ✅ 「つまり」の書き方

```
【つまりこういうこと】
[対象]は「[シンプルな表現]」です。[なぜ大事か / どう役立つか]。

例1:
「昆虫は『頭・胸・腹』の3つセット」。
「この3つが揃っていることが、昆虫を昆虫にしている秘密」。

例2:
「水は『自然界のおいしい設計』」。
「生き物を守るために、4℃以下で特別な振る舞いをする」。

例3:
「磁石は『見えない力の魔法使い』」。
「日常生活の便利さは、磁石のおかげでいっぱい成り立っている」。
```

## 🎓 学年別言語レベル早見表

### 小学3年生（Stage 3）
```
・ 短い文（15字以内）
・ 簡単な漢字（習う範囲）
・ 日常語中心
・ 比較的長い説明（平坦に）

例: 「昆虫の体は、3つの部分に分かれています」
```

### 小学4年生（Stage 4）
```
・ 複文（「～だから」「～なので」）
・ 因果関係を明確に
・ 「粒子が活動的に動く」などの視点

例: 「温度が上がると、粒子がソワソワと活発に動き始めます」
```

### 小学5年生（Stage 5）
```
・ 専門用語（ふりがな必須）
・ 「酵素」「オーキシン」などホルモン
・ 複雑な段階的説明

例: 「酵素という助手が、活発に働いて、発芽が始まります」
```

### 小学6年生（Stage 6）
```
・ 化学式・化学方程式
・ 深い原理的説明
・ 社会への応用

例: 「CₓHᵧ + O₂ → CO₂ + H₂O という化学反応」
```

## 🚀 実装の流れ

### Step 1: テンプレート選択
- パターン①②③のどれを使うか決める

### Step 2: 骨組み作成
- 見出しと段落数を先に決める
- 実生活例を3-4個リストアップ

### Step 3: 文字埋め込み
- 各セクションを段階的に展開
- 実生活例を具体化

### Step 4: 「つまり」作成
- 概念を統合した1文を作る
- なぜ大事かを追加

### Step 5: チェック
- 上のチェックリストを全項目確認

### Step 6: imageKeyword決定
- 視覚化に適したキーワードを作成

## 💡 よくある質問

### Q: 文字数が足りない場合は？
→ 「【実生活の例】」を1-2個追加、または各セクションの説明を詳しくする

### Q: 実生活例が思いつかない場合は？
→ 段階的な概念説明で補完。粒子・力・エネルギーのレベルで「見えない世界」を説明

### Q: 子どもに難しそうな場合は？
→ 言語レベルを下げる、比喩を追加、例を変える

### Q: imageKeyword をどうつけるか迷う場合は？
→ 「この説明の図解を作るなら、何を描く？」で考える
