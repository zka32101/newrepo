# 小学コレ！理科 — クイズ説明文拡張プロジェクト

## 📋 プロジェクト概要

**目標**: 47ステージ × 10問 = 470問のクイズ説明文を、子ども向けの充実した内容に拡張

**規模**: 150-200文字 → 400-600文字（2.5〜3倍増）

**期間**: 2026年9月2日より開始

---

## 📂 成果物一覧

このフォルダに以下の3つのドキュメントを作成しました：

### 1. **`quiz_explanation_enhancement_guide.dart`** (メイン成果物)

**内容**: 5つのサンプルステージ（50問）の完全な改善例

**構成**:
- Stage 3-001（昆虫と植物）: Q1, Q2, Q3 の拡張版
- Stage 3-005（磁石）: Q1, Q2, Q6 の拡張版
- Stage 4-005（金属・水・空気と温度）: Q1, Q2, Q5 の拡張版
- Stage 5-002（植物の発芽と成長）: Q1, Q3, Q7 の拡張版
- Stage 6-003（物の燃焼と化学変化）: Q1, Q3, Q5 の拡張版

**特徴**:
- Dart形式で即座に適用可能
- 各問に `imageKeyword` フィールドを追加
- commonMistakes, advancedLearning は未変更

**ファイルサイズ**: ~850行（すべてコピー&編集用に）

**使い方**: 
このファイルの例を参考に、残り420問に同じ構造を適用してください。

## 🎯 成果物の特徴

### ✅ Dart形式で即座に適用可能

```dart
// すぐにコピー&ペーストできます
'correctReason': '''【この形式で】拡張した説明文...''',
'imageKeyword': 'appropriate_keyword',
```

### ✅ 3つの応用パターンで全470問に対応

| パターン | 用途 | 例 |
|---------|------|-----|
| ① 複数要素 | 部位・器官の説明 | 昆虫の頭・胸・腹 |
| ② 条件・段階 | 条件の列挙 | 発芽の3条件 |
| ③ 原理・仕組み | メカニズム | 熱膨張の仕組み |

### ✅ 実生活例が豊富

各問に3-4個の具体例を挿入。子どもが「あ、見たことある！」と思える例ばかり。

### ✅ imageKeyword で将来の画像化に対応

```
'imageKeyword': 'insect_body_parts_diagram'
→ 将来、自動的に画像ライブラリと連携
```

## 💡 このプロジェクトの工夫

### 1️⃣ Dart形式で即座に統合可能

```dart
// 構造が明確で、プロジェクトにそのまま統合できます
final explanations_stage_3_001_enhanced = <int, Map<String, String>>{
  1: {
    'correctReason': '''...''',
    'commonMistakes': '...', // 変更なし
    'advancedLearning': '...', // 変更なし
    'imageKeyword': '...',
  },
};
```

### 2️⃣ 3つのテンプレートで全470問に対応

どのステージでも、3つのパターンのいずれかで対応可能。テンプレートの「穴埋め」で実装効率が向上。

### 3️⃣ 段階的な説明で「見える化」

粒子・力・エネルギーのレベルから、実生活への応用まで、段階的に説明することで、子どもが理解しやすくなります。

### 4️⃣ imageKeyword で将来の拡張性を確保

現在は文字列ですが、将来は自動的に画像ライブラリと連携する仕組みを用意しています。

## 📞 質問・フィードバック

### よくある質問

**Q1: 本当に470問すべてに適用できるのか？**
→ はい。3つのテンプレートで、すべての科学概念に対応できます。

**Q2: 実装にどのくらい時間がかかるか？**
→ 問あたり15-20分。42ステージで 420問 × 15分 = 105時間 ≈ 1.3人月

**Q3: 親が読むなら、もっと難しくてもいいのでは？**
→ いいえ。「子ども向け」がメインユーザーです。ふりがなとシンプルな言葉が重要。

**Q4: 文字数が600を超える場合は？**
→ その場合、セクションを分けるか、実生活例を削減してください。
